# Discord via Muxo

Connect Discord with `connect`, then `search` for the exact action (e.g. "send discord message"), and `run` it.

## Common actions

- Send a message to a channel.
- List/read channels and message history.
- Announce releases to a community channel.

## Defaults to remember

- The default channel or server.
- Whether to @mention a role.

## Rules & approvals

- Posting is a write: expect confirmation, and honor "ask before posting" rules.
- A posting cap prevents accidental channel spam.

## Gotchas

- Confirm the exact channel before posting; don't guess.
- Keep announcements short and human-readable; never paste raw JSON.
